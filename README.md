# OBS LuaTimer Script

**Автор:** [Rychka](https://t.me/rychkayt)

Этот скрипт предназначен для вывода текущего времени и обратного отсчета до заданных событий на стриме или записи в OBS Studio. Оптимизирован для минимальной нагрузки на систему за счет асинхронного обновления источников.

*   **Два режима работы:**
    *   **Один часовой пояс:** Отслеживает от 1 до 2 событий одновременно для конкретного часового пояса.
    *   **Мульти-таймеры:** Создает до 12 независимых таймеров для разных часовых поясов (от +1 до +12).
*   **Встроенные события:** Отсчет до Нового Года, Лета, Осени и Зимы (скрипт автоматически понимает, какой сейчас год, и переключается на следующий, если событие уже прошло).
*   **Разнообразие форматов:** 6 вариантов отображения времени.
*   **Глобальная коррекция:** Возможность сдвинуть время на заданное количество секунд (полезно, если надо корректировать для задержки ютуба).
*   **Асинхронная оптимизация:** Скрипт не фризит OBS. Вместо того чтобы обновлять все текстовые источники одновременно каждый кадр, он использует кэширование и очередь задач.

## Установка и использование в OBS

### Шаг 1: Подготовка источников
1. В нужной сцене OBS создайте обычные текстовые источники (**Текст GDI+**).
2. Назовите их понятно и оставьте их пустыми.

### Шаг 2: Установка скрипта
1. В верхнем меню OBS нажмите **Сервис (Services)** -> **Скрипты (Scripts)**.
2. Перейдите на вкладку **Скрипты** и нажмите плюсик **(+)** в левом нижнем углу.
3. Выберите скачанный файл `timer.lua`.

### Шаг 3: Настройка
После загрузки скрипта справа появится меню настроек:
*   **Часовой пояс ПК:** Обязательно укажите свой часовой пояс, чтобы математика времени работала корректно.
*   **Режим работы:** Выберите нужный режим. Интерфейс динамически изменится, скрыв ненужные настройки.
*   **Источники для Времени/Таймера:** В выпадающих списках выберите те текстовые источники, которые вы создали на Шаге 1. Скрипт автоматически начнет управлять их текстом.

p.s. после первой загрузки скрипта, все настройки могут отобразиться сразу. переключите параметр *режим работы* чтобы всё отображалось корректно. obs lua не позволяет исправить это.

## Как изменить код (Для разработчиков)

Скрипт написан модульно, поэтому добавлять новые возможности довольно легко.

### 1. Добавление кастомного события
Если вам нужно добавить отсчет до конкретной даты (например, до релиза своего проекта), измените два места в коде.

**Первое:** Добавьте математику в функцию `get_goal_ts`.
```lua
local function get_goal_ts(ev_type, sim_now)
    local d = os.date("*t", sim_now)
    local res = 0
    local y = d.year

    if ev_type == "ny" then
        res = os.time({year = y + 1, month = 1, day = 1, hour = 0, min = 0, sec = 0})
    -- ДОБАВЛЯЕМ СЮДА СВОЮ ДАТУ (например, 15 ноября 2026 года, 18:00)
    elseif ev_type == "rauth_release" then
        res = os.time({year = 2026, month = 11, day = 15, hour = 18, min = 0, sec = 0})
    -- ... дальше идут summer, autumn и т.д.
```

**Второе:** Добавьте опцию в интерфейс OBS. В функции `script_properties()` найдите места, где задаются списки событий, и добавьте свою строку:
```lua
    -- Блок первого события
    local e1 = obs.obs_properties_add_list(p, "single_ev1", "[Соб. 1] Отсчет до:", obs.OBS_COMBO_TYPE_LIST, obs.OBS_COMBO_FORMAT_STRING)
    obs.obs_property_list_add_string(e1, "Релиз RAuth", "rauth_release") -- ВАША СТРОКА
    obs.obs_property_list_add_string(e1, "До Нового Года", "ny")
    -- ... (сделайте то же самое для e2 и e_multi, если нужно)
```

### 2. Добавление нового формата вывода
В функции `format_diff` добавьте новое условие (например, `fmt_type == "6"`):
```lua
    if fmt_type == "6" then
        return string.format("Осталось: %dд %dч %dм", days, hrs, mins)
    end
```
Затем в утилиту `inject_formats(prop_obj)` добавьте регистрацию этого формата для интерфейса:
```lua
    obs.obs_property_list_add_string(prop_obj, "Текстовый формат (Осталось: Хд Хч)", "6")
```

### 3. Расширение лимита мульти-таймеров
По умолчанию скрипт ограничен 12 поясами. Чтобы изменить это количество, воспользуйтесь поиском по коду и замените `12` на нужное число в трех местах:
1. В функции `main_clock_pulse()` — цикл расчетов.
2. В функции `refresh_ui()` — цикл обновления видимости элементов интерфейса.
3. В функции `script_properties()` — цикл создания полей в настройках скрипта.
